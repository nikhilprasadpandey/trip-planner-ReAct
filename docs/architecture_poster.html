⚡ Caches · two tiers
  • Route cache (Redis) — 600s TTL · key: origin:dest:date:cabin
  • Semantic Q&A cache (in-process) — job_level bucket · cosine ≥ 0.70
  • Redis unset → falls back to in-process, same interface
a cache is never allowed to be why a request fails — an unreachable Redis degrades to "treat as a miss," never a crash

  • Approval Gate — book_flight blocked without a granted record
  • Audit trail — SQLAlchemy, append-only, PII-hashed
  • Golden eval suite — 14/14 (3 easy · 4 medium · 3 hard · 4 adversarial)
